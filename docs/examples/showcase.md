# 综合体验

在一个页面体验全部 40 个公开组件：先操作项目工作台，再展开下方组件卡片查看具体场景及源码。主题统一使用页面底部的全站选择器，切换主题会保留当前填写和选择状态。

## 项目工作台

- **资源与布局**：展开目录、选择文件，拖动分隔条调整面板；工具栏可刷新、展开目录或打开菜单。
- **设置与表单**：填写名称、语言、导出格式和百分比，保存时显示真实 `FormData`；已修改高亮、默认恢复和必填校验一起工作。
- **分区与视图**：取消自动化分区的勾选可折叠并禁用内部控件；拖动标签页或分区标题到下方空容器可重组视图。
- **任务与结果**：启动模拟构建，观察进度条、进度环、表格状态和日志联动；运行中可以取消。移动端自动改为上下布局，表格显示每列名称。

此示例只操作本地预览状态。代码视图包含完整 HTML、CSS 和 JavaScript，可用作扩展 Webview 的组合起点。
