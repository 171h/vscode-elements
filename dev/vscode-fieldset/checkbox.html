Fieldset checkbox

The checkbox is placed on the top-right corner of the border, aligned with the legend. It disables the content while unchecked and applies the selected unchecked-mode. The height transition is animated.

Unchecked modes

Visible

Content stays in place while the checkbox is unchecked.
Collapsed

The content is hidden, the header stays visible.
Minimal

Only the checkbox and its label stay visible.

Custom behavior

The vsc-fieldset-checked-change event is cancelable and the checkedChange callback can return false to skip the default enable, disable and collapse handling.

Callback

Callback state: enabled
Prevent default

The event listener calls preventDefault(), so the content stays enabled.
