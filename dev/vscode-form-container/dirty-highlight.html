表单容器的已修改状态

修改表单中的控件后，该表单所有控件的背景变为浅蓝色。同一时间仅高亮一个表单：修改另一表单后，之前的表单立即恢复正常状态。

浅色主题使用 #eff3ff。深色及高对比度主题使用调色板中的对应色调，可通过下方主题选择器应用到页面。

主题

Kind of the theme Light Dark High contrast High contrast light The kind is published on the body element, like VS Code does it. Modify a control to see the state of the selected theme.
